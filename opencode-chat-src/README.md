# Slonobass agent — исходники

Портативная программа чата для Windows вокруг движка opencode.
Один файл кода: `chat.cs` — C# 5, WinForms, .NET Framework 4.8.

Раньше программа называлась OpenCode Chat.

## Как собрать

Нужен .NET SDK (подойдёт любой свежий, 6/7/8) и Windows или Linux —
сборка кросс-платформенная, на выходе всё равно Windows-программа.

    dotnet build -c Release

Готовый файл появится в `bin/Release/SlonobassAgent.exe`.
Переименуйте его в `Slonobass-Agent.exe`, положите рядом `.exe.config`
и папки `engine` и `projects` из релиза — программа ищет движок
относительно своего расположения.

Сборка на Linux без .NET Framework:

    export DOTNET_SYSTEM_GLOBALIZATION_INVARIANT=1
    dotnet build -c Release

## Что уже лежит в релизе

Готовые сборки: https://github.com/magiyastraha-tech/sandfly-scripts/releases
Тег `slonobass-agent-N` — версия N. В ZIP уже есть движок opencode,
llama.cpp для офлайн-моделей GGUF и инструкция для пользователя.

## Обновление

Кнопка «Обновить программу» сверху спрашивает у GitHub API список релизов,
ищет наибольший номер в тегах `slonobass-agent-N` и сравнивает его
с `AppVersion` в `chat.cs`. Если номер больше — скачивает ZIP этого релиза.

Файлы заняты работающей программой, поэтому обновляет их отдельный помощник:
программа распаковывает ZIP во временную папку, копирует туда себя и запускает
копию с ключом `--apply-update <распакованное> <папка программы> <PID>`,
затем закрывается. Помощник ждёт выхода процесса, копирует изменившиеся файлы
(папки `projects` и `log` не трогает) и запускает новую версию.
Журнал обновления — `%TEMP%\SlonobassAgent-update\update.log`.

При каждом релизе поднимайте `AppVersion` в `chat.cs` до номера тега,
иначе программа не увидит обновление.

## Устройство

- `chat.cs` — всё окно, переписка, отправка запросов движку, офлайн-модели.
- `SlonobassAgent.csproj` — проект сборки (net48).
- Ключи провайдеров не хранятся в коде: ключ вводится в окне «Мой профиль»
  и лежит на компьютере пользователя в зашифрованном виде (DPAPI).

## Провайдеры

Кнопка «Другие сервисы…» подключает любой сервис с адресом в стиле OpenAI:
ключ вводится в окне, программа сама забирает список моделей с `…/models`
и пишет провайдер `other` в `projects/opencode.json` (ключ передаётся
движку переменной окружения `POLZA_API_KEY`, сам ключ лежит в файле под DPAPI):

- Polza.ai — `https://polza.ai/api/v1`, ключ `pza_…`, модели вида `vendor/model`;
- AnyModel — `https://anymodel.org/v1`, один ключ на GPT, Claude, Gemini, DeepSeek;
- «Свой адрес…» — любой совместимый шлюз.

## Правила для модели

При старте программа пишет `projects/AGENTS.md` (файл помечен
`<!-- Slonobass agent -->`; чужой файл без метки не трогается) и задаёт
права в `opencode.json`: `webfetch` разрешён, встроенный `websearch` выключен.
В неинтерактивном запуске движок не может ответить на запрос подтверждения
(«Cancelled a request for input this run cannot answer») и обрывает ответ,
поэтому поиск идёт не встроенным инструментом, а через `webfetch`:
страница выдачи DuckDuckGo Lite, затем Bing, затем сами найденные ссылки.

## Управление перепиской

Переписка — системный список: один пункт списка = одно целое сообщение.
Экранный диктор читает выделенный пункт целиком, стрелками список управляет
сам, отдельные события озвучки программе не нужны.

- Стрелки вверх и вниз — по целым сообщениям.
- Home и End — к первому и последнему сообщению.
- Ctrl со стрелками — по первым сообщениям каждого собеседника.
- Ctrl+Enter — открыть ссылку из сообщения.
- Ctrl+C — скопировать выбранное сообщение.
