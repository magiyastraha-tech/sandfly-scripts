# Скрипты для SandFly

Здесь лежат скрипты для экранного диктора SandFly. Каждый файл — отдельный
скрипт для одного приложения.

Имя файла совпадает с внутренним идентификатором скрипта (`id` из manifest).
Так SandFly находит свежую версию в источнике и обновляет установленный
скрипт сам — по имени файла, а не только по той ссылке, откуда его когда-то
скачали.

## Как подключить как источник

1. Откройте SandFly.
2. Настройки, затем Приложения, затем Скрипты, затем Источники скриптов.
3. Add source — добавьте этот адрес:

   github.com/magiyastraha-tech/sandfly-scripts

4. В списке появятся скрипты из этого репозитория, их можно установить.

SandFly раз в день сам проверяет, не вышла ли новая версия, и обновляет
скрипты, установленные из этого источника. Вручную ничего скачивать не нужно.
Кнопка «Проверить обновления» на экране скриптов делает то же самое сразу.

## Какие скрипты есть

**Slonobass YMusic** — для YMusic (io.ymusic.android), id `ymusic.video_rows`.

В списках строка видео, клипа и трансляции читает только название и время. В
меню действий три пункта: «Канал: …», «Остальное: …» с просмотрами и датой
публикации, и «Ещё» — та самая кнопка из строки. Сборка одна и та же для
любой строки: видео, клипа, трансляции, микса и плейлиста, — пункт появляется,
если данные в строке есть. У микса и плейлиста канала, просмотров и даты нет,
поэтому название читается целиком, а в меню действий остаются «Остальное»,
если там что-то есть, и «Ещё». Отдельная кнопка «Ещё» убрана из обхода в
любой строке списка — и в «Подписках», и на главной.
При входе в приложение и при каждом открытии вкладки «Подписки» фокус всегда
встаёт на раздел «Новые»: дальше можно сразу идти по видео свайпом вправо.
Если фокус уже стоит на строке видео, скрипт его не отбирает.

В настройках скрипта: «Что считать временем» — длительность (по умолчанию),
когда опубликовано, или и то и другое; переключатель «Короткая строка», чтобы
вернуть прежний вид; переключатель «Фокус на «Новые»».

**Slonobass Теле2** — для приложения «Мой Теле2» (ru.tele2.mytele2),
id `wam.tele2-summary`.

Одной командой (жест `sf` плюс `s`, либо через меню команд) читает номер,
баланс, остатки гигабайт, минут и SMS, тариф и число подключённых услуг.

Нижние вкладки называет коротко, только именем раздела. Верхний ряд
(профиль, уведомления, поиск) собирает в один пункт, переключение между ними —
через меню действий. Блок с номером и остатками тоже собирает в один пункт:
в меню действий «Пополнить баланс», «Гигабайты», «Минуты», «SMS», причём
в названиях видны текущие остатки. Рекламный баннер пропускается при листании.
При входе в приложение фокус всегда встаёт на блок с номером.

В настройках скрипта есть переключатель «Распознавать цифры по картинке»:
он нужен для остатка гигабайт, которого приложение не отдаёт диктору.
Требует Android 11 и новее. Добавляет около секунды. И переключатель
«Фокус на блок с номером» — можно выключить автоматический фокус.

**Slonobass Nekogram** — для Nekogram (tw.nekomimi.nekogram),
id `wam.nekogram-actions`.

Убирает из свайпа по сообщениям кнопку «Комментарии», кнопку «Поделиться» и
кнопку расшифровки у голосовых: это были лишние остановки посреди текста.
«Комментарии» и «Поделиться» остаются доступны в меню действий самого
сообщения: «Комментарии» — первым пунктом, выше «Ответить», «Поделиться» —
последним, внизу. Кнопка расшифровки в меню не возвращается.

Пункт выше действий приложения умеет ставить SandFly со скриптовым API 5 —
в выпуске 0.5.0 этого ещё нет, там «Комментарии» окажутся в конце меню; в
текущей dev-сборке и в следующем выпуске всё на своих местах. Работает и в
каналах, и в обычных чатах, на русском и английском.

При открытии приложения фокус встаёт на список чатов, на первый чат. Внутри
чата, в настройках и на других внутренних экранах скрипт фокус не трогает.
Если приложение, дорисовывая экран, уводит фокус на заголовок наверху, скрипт
проверяет, где фокус оказался, и возвращает его в список — до четырёх попыток
за первую секунду. Переключатель «Фокус на список чатов» в настройках скрипта
отключает это, а команда «Перейти к списку чатов» переводит фокус вручную.

При входе в любой чат, где есть заголовок «Непрочитанные сообщения», фокус
сам встаёт на этот заголовок — дальше можно сразу идти свайпом по
непрочитанному. Сам заголовок фокус не берёт, поэтому фокус встаёт на
ближайший элемент, который его берёт. Попытка в чате одна: скрипт пробует
до трёх раз, пока чат дорисовывается, и потом в этом чате фокус больше не
переставляет — иначе при каждом обновлении экрана он отбирал бы фокус назад.
Если заголовка нет, фокус остаётся там, где его поставил SandFly.
Отключается переключателем «Фокус на непрочитанные».

Жест «два пальца, дважды» записывает голосовое сообщение: нажимает
микрофон и ведёт палец вверх до замка, чтобы запись продолжалась с
отпущенным пальцем. Тот же жест второй раз нажимает отправку и голосовое
уходит. Если кнопки записи нет, скрипт говорит: «Кнопка записи не найдена»;
если отправку нажать не удалось — «Отправить не получилось», и тогда её можно
нажать вручную. Нажать на экран скрипт может только на Android 11 и новее.
Жест можно переназначить на странице скрипта.

Жест тремя пальцами с удержанием читает статус контакта в открытом чате:
«онлайн», «был(а) в 16:25», «был(а) недавно». Если Nekogram склеил имя и статус
в одну подпись шапки, проговаривается только строка статуса. Скрипт ничего не
нажимает, только проговаривает. Статус ищется в шапке чата, выше ленты сообщений, поэтому
похожий текст из самого сообщения за статус не сойдёт. Если статуса нет — в
группе, в канале или когда активность скрыта — скрипт говорит «Статус не
найден»; на главном экране — «Чат не открыт».

Там же команда «Перейти к непрочитанным» — переводит фокус на заголовок
вручную. Если заголовка нет, она так и говорит: «Заголовок непрочитанных не
найден»; если заголовок есть, но фокус на него не встаёт — «Заголовок
непрочитанных не берёт фокус».

Если прежняя версия этого скрипта (от другого автора, id
`nekogram-message-actions`) уже установлена, её лучше удалить: у неё другой
идентификатор, и SandFly будет держать оба скрипта сразу, а пункты меню
задвоятся.

**Slonobass Переводчик** — переводчик текста в любом приложении,
id `wam.translator`.

Команда «Перевести текст на выбранный язык» есть только в главном меню
команд, жест за ней не закреплён. При запуске открывается окно «Куда
перевести?»: сначала список избранных языков, по умолчанию пустой, следом
кнопка «Все языки». Двойной удар по языку сразу переводит на него.

У каждого языка в избранном в меню действий три пункта: «Переместить выше»,
«Переместить ниже» и «Удалить». Порядок избранного сохраняется.

Язык, на который только что перевели, сам встаёт первым в избранном: до
частого языка дальше один удар. Язык, которого в избранном нет, порядок не
трогает.

Кнопка «Все языки» открывает второе окно: сверху поиск, ниже полный список
языков. Поиск ищет и по названию, и по коду языка, регистр не важен. Двойной
удар по языку переводит на него, а в меню действий у каждой строки есть
«Добавить в избранное».

Текст берёт из поля ввода, иначе из элемента в фокусе. Если там пусто —
предлагает на выбор последнее произнесённое, текст из буфера обмена или ввод
вручную. Длинный текст режется на куски до 4500 символов, чтобы уложиться в
лимит службы перевода.

Перевод по умолчанию возвращается в поле ввода на место исходного текста; если
поле уже не активно или текст в нём успели изменить, перевод показывается в
окне. Внизу главного окна есть флажок «Копировать в буфер» — тот же
переключатель, что и в настройках скрипта. Когда он включён, перевод
копируется в буфер обмена после любого перевода: и когда вставляется в поле
ввода, и когда показывается в окне. В настройках скрипта два переключателя:
«Вставлять перевод обратно в поле ввода» и «Копировать перевод в буфер
обмена».

**Slonobass Google Messages** — для Google Messages
(com.google.android.apps.messaging), id `wam.google-messages-actions`.

В меню действий каждого разговора в списке добавляет три пункта: «Отметить
как прочитанное», «Удалить разговор» и «Добавить контакт». Скрипт повторяет
то, что делают руками: удерживает разговор, во всплывшем меню открывает
«Другие параметры» и нажимает нужный пункт; если пункт не нашёлся, говорит
об этом и закрывает меню. Нажатия идут без задержек, как в оригинальном
скрипте: меню открывается и закрывается быстрее, чем диктор успевает его
зачитать, поэтому действие проходит почти молча.

Отмечает только прочитанным: непрочитанным скрипт не помечает никогда. Если
разговор уже прочитан, скрипт говорит «Уже прочитано» и ничего не нажимает.

Удаление подтверждает сам: после пункта «Удалить разговор» открывается диалог
«Отправить чат в корзину?», и скрипт жмёт его кнопку «Отправить в корзину» —
разговор сразу уходит в корзину, ничего нажимать руками не нужно. Кнопка
ищется по id `android:id/button1`, а по подписям — только если id не нашёлся:
подпись есть и в заголовке диалога, и поиск по тексту мог бы попасть в
заголовок. Ищется и в остальных окнах, а не только в активном: диалог может
появиться раньше, чем меню успеет закрыться. Если кнопка не принимает
программное нажатие, скрипт тычит по ней пальцем.

Подтверждение нажимается отдельной короткой задачей через задержку: у каждого
вызова в скрипт есть две секунды, и раньше поиск кнопки не укладывался в них —
скрипт молча обрывался, а диалог оставался висеть.

При входе в приложение скрипт ставит фокус на первый разговор в списке — не
важно, прочитан он или нет. Событие входа срабатывает, когда Google Messages
выходит на передний план, а не при переходах между экранами внутри него:
при выходе из чата назад в список фокус не переводится и остаётся на том
разговоре, где был. Если на экране открыт чат, скрипт тоже ничего не делает.
Перевод можно выключить переключателем «При запуске ставить фокус на первый
чат» в настройках скрипта.

Основа — скрипт `google-messages-actions.lua` автора Surendra из
официального репозитория aaron-gh/sandfly-scripts (лицензия Apache 2.0).
Переведены названия пунктов, сообщения и комментарии; кнопки ищутся и по
русским, и по английским подписям, поэтому скрипт работает при любом языке
интерфейса. Подпись SandFly при переводе снята: диктор поставит скрипт как
неподписанный, и отметьте его как изменённый — обновления из источника могут
не приходить сами.

**Slonobass Телефон Samsung** — для штатного телефона Samsung
(com.samsung.android.dialer), id `wam.samsung-call-log-actions`.

Один скрипт на два списка телефона: журнал вызовов и вкладку «Контакты». Сам
список не перестраивает: строки читаются как раньше, только у развёрнутой
строки в конце добавляются два слова — «Строка развёрнута» в журнале,
«Контакт развёрнут» в контактах. Иначе свёрнутая и раскрытая строка звучат
одинаково.

В журнале вызовов меню действий каждой строки получает шесть пунктов:
«Позвонить», «Сведения», «Добавить контакт», «Сообщение», «Видеовызов» и
«Воспроизвести запись». В контактах — четыре: «Позвонить», «Сообщение»,
«Видеовызов», «Сведения».

Свёрнутую строку скрипт перед действием разворачивает сам: нажимает её, ждёт,
пока под ней появятся кнопки, и уже потом нажимает нужную. Уже развёрнутую
строку не нажимает — нажатие свернуло бы её обратно. Поэтому действия работают
в обоих состояниях одинаково, и разворачивать руками перед выбором пункта не
нужно. Если после нажатия блок так и не появился, скрипт говорит «Не получилось
развернуть строку» и ничего не нажимает.

«Добавить контакт» для знакомого номера ничего не нажимает, а говорит «Номер
уже в контактах»: в журнале имя контакта стоит вместо номера. «Воспроизвести
запись» смотрит на значок записи в строке — если вызов не записывался, говорит
«Записи этого вызова нет» и строку не разворачивает.

Кнопки ищутся и по русским, и по английским подписям, поэтому скрипт работает
при любом языке интерфейса.

Имя файла и id остались прежними: так уже установленный скрипт обновится сам, а
не задвоит пункты меню рядом со старой версией.

**Slonobass Почта Samsung** — для штатной почты Samsung
(com.samsung.android.email.provider), id `samsung-email-delete-action`.

В меню действий каждого письма в списке появляется пункт «Удалить письмо», а
если в списке осталось одно письмо — «Удалить всё», как называется кнопка в
самом приложении.

Скрипт повторяет то, что делают руками: нажимает с удержанием на строке
письма, дожидается нижней панели и жмёт на ней «Удалить». Удержание делается
настоящим касанием: палец ставится в центр строки и держится шестьсот
миллисекунд. Программное нажатие с удержанием выделяет письмо, но нижнюю
панель у почты не показывает, поэтому касание основное, а программное
удержание осталось запасным путём.

Кнопка ищется и в активном окне, и в остальных окнах, по id `delete_item` и по
подписи. Если приложение спросило подтверждение, скрипт жмёт и его. Если
панель так и не появилась, скрипт говорит «Панель с удалением не появилась» и
больше ничего не нажимает.

Если на письме уже стоит флажок режима выбора, скрипт ничего не делает и
говорит «Сначала выйдите из режима выбора»: удержание сняло бы отметку, а
какое письмо удалять — неизвестно.

Удержание и поиск панели идут отдельными задачами через задержку: у каждого
вызова в скрипт две секунды, и касание с ожиданием в них не укладывалось.

Имя файла совпадает с id намеренно: прежняя версия скрипта (тоже с id
`samsung-email-delete-action`) обновится сама, а не задвоит пункт меню.

**Slonobass Google Play** — для Google Play (com.android.vending),
id `wam.google-play-updates-focus`.

На экране «Управление устройством и приложениями» фокус сам встаёт на строку
обновлений, и она читается одной фразой: «Доступны обновления. 6 обновлений
ожидают скачивания» или «Все приложения обновлены. Последнее обновление: только
что». Кнопки «Обновить все» и «Подробнее» в конце строки на слух не читаются —
они остаются доступны свайпом вправо.

Если Play дорисует строку уже после открытия экрана, скрипт её дождётся и
переведёт фокус. Если человек сам ушёл со строки вниз, фокус назад не
отбирается, сколько бы раз экран ни обновлялся. На других экранах Play скрипт
молчит. Если строку не удаётся сфокусировать, скрипт сам проговаривает, что на
ней написано.

В настройках скрипта переключатель «Фокус на обновления»; в меню команд есть
ручной переход «Перейти к обновлениям».

**Slonobass Файловый менеджер** — для файлового менеджера «Файловый менеджер +»
(com.alphainventor.filemanager), id `filemanager-select`.

Кнопка выбора рядом с каждой строкой списка убрана из обхода свайпами: на
каждом файле это была лишняя остановка. В меню действий строки, которое
открывается жестом вверх или вниз, появились свои пункты, и они стоят выше
действий приложения: «Выбрать», «Копировать», «Переместить», «Удалить»,
«Переименовать», «Поделиться» и «Сжатие».

«Выбрать», «Копировать», «Переместить» и «Удалить» идут через кнопку выбора
из строки: скрипт нажимает её, дожидается нижней панели и нажимает на ней
нужную кнопку. Держать палец не нужно, поэтому действие срабатывает быстрее,
чем раньше. Если панель после выбора не появилась, в запасе остаётся прежнее
удержание настоящим касанием: палец ставится в центр строки и держится
шестьсот миллисекунд. Программное удержание строку выделяет, но нижнюю панель
приложение не показывает.

«Поделиться» и «Сжатие» устроены так же: строка выделяется кнопкой выбора,
затем скрипт нажимает на нижней панели «Ещё» и выбирает нужный пункт во
всплывающем меню. У архивов — zip, rar, 7z, tar, gz, xz и других — пункт
называется «Извлечение» вместо «Сжатие», и в меню «Ещё» скрипт выбирает
извлечение. Подписи «Ещё» и пунктов меню ищутся по тексту, потому что их id у
приложения могут меняться от версии к версии.

Пункты есть только там, где фокус стоит на файле или папке: у самой панели
приложения, у заголовка и у поиска их нет. Строка ищется по родителям элемента,
из которого открыто меню, поэтому действие не уйдёт в соседний файл. Если
панель уже открыта, выбор не повторяется — нужная кнопка нажимается сразу.

После «Переименовать» скрипт ставит курсор в поле с именем, чтобы можно было
печатать сразу. Переименование по-прежнему идёт через удержание: на нижней
панели эта кнопка есть всегда. Если панель, кнопка или пункт меню не нашлись,
скрипт говорит об этом и ничего не нажимает. Удаление показывает
подтверждение, и его нужно пройти обычным образом.

Выбор строки и ожидание панели разнесены по задачам через задержку: у действия
около двух секунд, а нажатие с ожиданием панели в них не укладывается.

Имя файла и id совпадают намеренно: так версия, установленная вручную, потом
обновится с источника, а не задвоит пункты меню.

**Slonobass КИБЕРПОРТАЛ БС** — для «КИБЕРПОРТАЛ БС» (com.cybportal.bs), id `cyberportal-vpn`.

Версия 1.1 — под новый интерфейс приложения. Главный экран причёсан под слух:
декоративные надписи «КИБЕРПОРТАЛ // БС», «КИБЕРПОРТАЛ», «СТАРТ», «УЗЕЛ», «N»
и номера режимов убраны из обхода. Переключатель ВПН стал одной остановкой,
которая сразу называет состояние: «ВПН подключён, кнопка» или «ВПН отключён,
кнопка». Двойное касание переключает, а меню действий предлагает понятный
пункт: «Включить ВПН» или «Отключить ВПН».

Когда состояние меняется, скрипт говорит об этом сам, кто бы ни нажал: он сам,
двойное касание по переключателю или автоподключение приложения. Промежуточные
надписи тоже переводятся — «ВПН подключается», «ВПН отключается», «ВПН: ошибка
подключения». Если приложение за три с половиной секунды не поменяло надпись,
скрипт говорит, что состояние не изменилось.

При открытии приложения фокус переводится на переключатель, если он нигде или
стоит на скрытой строке состояния, — тогда первое, что слышно, это состояние и
то, что перед нами кнопка. Если фокус уже стоит на списке, скрипт его не
отбирает. Строки режимов, стран и серверов читаются целиком, заголовок панели —
это выбранный режим или узел плюс пинг, если приложение его показывает:
«Выбор сервера: Надёжно, наиболее стабильный, пинг 87 мс». Поле подсказки
приложение теперь использует двояко: при подключении там страна выхода (флаг
убирается, остаётся «Финляндия»), а при отключении — подсказка «Нажми кнопку
слева», и она читается как есть, без приставки «Страна». Трафика на главном
экране больше нет, поэтому и строки о нём там нет; если приложение вернёт её,
прежняя формулировка «Трафик: принято 14,1 мегабайт; отправлено 3,5 мегабайт»
снова заработает. Вкладки внизу названы «Вкладка ВПН» и «Вкладка Настройки»,
а картинки и подписи внутри них из обхода убраны.

В настройках скрипта два переключателя: «При открытии ставить фокус на
переключатель ВПН» и «Говорить о подключении и отключении». В меню команд —
«ВПН: включить или отключить», «ВПН: сообщить состояние» и «ВПН: перейти к
выбору сервера».

**Slonobass v2RayTun** — для v2RayTun (com.v2raytun.android), id `v2raytun-vpn`.

Главный экран приведён к одному действию. Переключатель ВПН — там он был
RelativeLayout без имени, с лампочкой, у которой описание «v2RayTun», — стал
одной остановкой: «ВПН отключён, кнопка». Двойное касание переключает, а скрипт
сам говорит о результате: «ВПН подключается», «ВПН подключён», «ВПН отключён»,
«ВПН: ошибка подключения». Надпись состояния и лампочка из обхода убраны, в меню
действий у переключателя пункт с честным названием — «Включить ВПН» или
«Отключить ВПН».

Строка сервера читается одной фразой без флагов, лишних пробелов и «v2RayTun»:
«Германия, VLESS, TCP» или «LTE Германия номер 1, 0 из 20 гигабайт, 24 часа,
HYSTERIA2». В меню действий строки — «Подключиться к серверу», «Показать QR-код»
и «Изменить». У подписки названы кнопки обновления и разворота списка, трафик
произносится словами: «Трафик: 16,9 из 600 гигабайт», срок — «Подписка активна
до 29 ноября 2026, 14:00», дата обновления — «Подписка обновлена 18 ноября 2026 в
17:15». Секундомер говорит «Время подключения: 12 минут», вкладки внизу названы
«Вкладка Подключение» и «Вкладка Настройки».

При открытии фокус переводится с кнопки «Добавить» на переключатель ВПН. В
настройках — «При открытии ставить фокус на переключатель ВПН» и «Говорить о
подключении и отключении». В меню команд — «ВПН: подключить или отключить»,
«ВПН: сообщить состояние», «ВПН: перейти к списку серверов» и «Подписка:
обновить».

## Требования

SandFly версии не ниже 2. wam.google-messages-actions проверен на API 1,
wam.tele2-summary — на API 3, ymusic.video_rows и wam.translator — на API 4,
wam.nekogram-actions, samsung-email-delete-action,
wam.google-play-updates-focus, filemanager-select, cyberportal-vpn и
v2raytun-vpn — на API 5.
wam.samsung-call-log-actions написан под API 2: без него остаётся только
программное нажатие, а часть кнопок его не принимает.

Касание по экрану, которым samsung-email-delete-action удерживает строку,
работает на Android 11 и новее. Без него остаётся программное удержание: оно
письмо выделит, но нижнюю панель не покажет — удаление тогда не пройдёт.
