# Скрипты для SandFly

Здесь лежат скрипты для экранного диктора SandFly. Каждый файл — отдельный
скрипт для одного приложения.

Имя файла совпадает с внутренним идентификатором скрипта (`id` из manifest).
Так SandFly находит свежую версию в источнике и обновляет установленный
скрипт сам — по имени файла, а не только по той ссылке, откуда его когда-то
скачали.

## Как подключить как источник

1. Откройте SandFly.
2. Настройки, затем Приложения, затем Скрипты, затем Источники скриптов.
3. Add source — добавьте этот адрес:

   github.com/magiyastraha-tech/sandfly-scripts

4. В списке появятся скрипты из этого репозитория, их можно установить.

SandFly раз в день сам проверяет, не вышла ли новая версия, и обновляет
скрипты, установленные из этого источника. Вручную ничего скачивать не нужно.
Кнопка «Проверить обновления» на экране скриптов делает то же самое сразу.

## Какие скрипты есть

**ymusic.video_rows.lua** — для YMusic (io.ymusic.android), id `ymusic.video_rows`.

В списках видео строка читает только название и время. В меню действий три
пункта: «Канал: …», «Остальное: …» с просмотрами и датой публикации, и «Ещё» —
та самая кнопка из строки видео. Отдельная кнопка «Ещё» из обхода убрана.
При входе в приложение и при каждом открытии вкладки «Подписки» фокус всегда
встаёт на раздел «Новые»: дальше можно сразу идти по видео свайпом вправо.
Если фокус уже стоит на строке видео, скрипт его не отбирает.

В настройках скрипта: «Что считать временем» — длительность (по умолчанию),
когда опубликовано, или и то и другое; переключатель «Короткая строка», чтобы
вернуть прежний вид; переключатель «Фокус на «Новые»».

**wam.tele2-summary.lua** — для приложения «Мой Теле2» (ru.tele2.mytele2),
id `wam.tele2-summary`.

Одной командой (жест `sf` плюс `s`, либо через меню команд) читает номер,
баланс, остатки гигабайт, минут и SMS, тариф и число подключённых услуг.

Нижние вкладки называет коротко, только именем раздела. Верхний ряд
(профиль, уведомления, поиск) собирает в один пункт, переключение между ними —
через меню действий. Блок с номером и остатками тоже собирает в один пункт:
в меню действий «Пополнить баланс», «Гигабайты», «Минуты», «SMS», причём
в названиях видны текущие остатки. Рекламный баннер пропускается при листании.
При входе в приложение фокус всегда встаёт на блок с номером.

В настройках скрипта есть переключатель «Распознавать цифры по картинке»:
он нужен для остатка гигабайт, которого приложение не отдаёт диктору.
Требует Android 11 и новее. Добавляет около секунды. И переключатель
«Фокус на блок с номером» — можно выключить автоматический фокус.

**wam.nekogram-actions.lua** — для Nekogram (tw.nekomimi.nekogram),
id `wam.nekogram-actions`.

Убирает из свайпа по сообщениям кнопку «Поделиться» и кнопку расшифровки у
голосовых: это были лишние остановки посреди текста. Обе кнопки остаются
доступны в меню действий самого сообщения — «Поделиться» и «Показать
расшифровку». Работает и в каналах, и в обычных чатах, на русском и английском.

При открытии приложения фокус встаёт на список чатов, на первый чат. Внутри
чата, в настройках и на других внутренних экранах скрипт фокус не трогает.
Если приложение, дорисовывая экран, уводит фокус на заголовок наверху, скрипт
проверяет, где фокус оказался, и возвращает его в список — до четырёх попыток
за первую секунду. Переключатель «Фокус на список чатов» в настройках скрипта
отключает это, а команда «Перейти к списку чатов» переводит фокус вручную.

При входе в любой чат, где есть заголовок «Непрочитанные сообщения», фокус
сам встаёт на этот заголовок — дальше можно сразу идти свайпом по
непрочитанному. Сам заголовок фокус не берёт, поэтому фокус встаёт на
ближайший элемент, который его берёт. Попытка в чате одна: скрипт пробует
до трёх раз, пока чат дорисовывается, и потом в этом чате фокус больше не
переставляет — иначе при каждом обновлении экрана он отбирал бы фокус назад.
Если заголовка нет, фокус остаётся там, где его поставил SandFly.
Отключается переключателем «Фокус на непрочитанные».

Жест «два пальца, дважды» записывает голосовое сообщение: нажимает
микрофон и ведёт палец вверх до замка, чтобы запись продолжалась с
отпущенным пальцем. Тот же жест второй раз нажимает отправку и голосовое
уходит. Если кнопки записи нет, скрипт говорит: «Кнопка записи не найдена»;
если отправку нажать не удалось — «Отправить не получилось», и тогда её можно
нажать вручную. Нажать на экран скрипт может только на Android 11 и новее.
Жест можно переназначить на странице скрипта.

Жест тремя пальцами с удержанием читает статус контакта в открытом чате:
«онлайн», «был(а) в 16:25», «был(а) недавно». Если Nekogram склеил имя и статус
в одну подпись шапки, проговаривается только строка статуса. Скрипт ничего не
нажимает, только проговаривает. Статус ищется в шапке чата, выше ленты сообщений, поэтому
похожий текст из самого сообщения за статус не сойдёт. Если статуса нет — в
группе, в канале или когда активность скрыта — скрипт говорит «Статус не
найден»; на главном экране — «Чат не открыт».

Там же команда «Перейти к непрочитанным» — переводит фокус на заголовок
вручную. Если заголовка нет, она так и говорит: «Заголовок непрочитанных не
найден»; если заголовок есть, но фокус на него не встаёт — «Заголовок
непрочитанных не берёт фокус».

Если прежняя версия этого скрипта (от другого автора, id
`nekogram-message-actions`) уже установлена, её лучше удалить: у неё другой
идентификатор, и SandFly будет держать оба скрипта сразу, а пункты меню
задвоятся.

**wam.translator.lua** — переводчик текста в любом приложении,
id `wam.translator`.

Команда «Перевести текст на выбранный язык» есть только в главном меню
команд, жест за ней не закреплён. При запуске открывается окно «Куда
перевести?»: сначала список избранных языков, по умолчанию пустой, следом
кнопка «Все языки». Двойной удар по языку сразу переводит на него.

У каждого языка в избранном в меню действий три пункта: «Переместить выше»,
«Переместить ниже» и «Удалить». Порядок избранного сохраняется.

Язык, на который только что перевели, сам встаёт первым в избранном: до
частого языка дальше один удар. Язык, которого в избранном нет, порядок не
трогает.

Кнопка «Все языки» открывает второе окно: сверху поиск, ниже полный список
языков. Поиск ищет и по названию, и по коду языка, регистр не важен. Двойной
удар по языку переводит на него, а в меню действий у каждой строки есть
«Добавить в избранное».

Текст берёт из поля ввода, иначе из элемента в фокусе. Если там пусто —
предлагает на выбор последнее произнесённое, текст из буфера обмена или ввод
вручную. Длинный текст режется на куски до 4500 символов, чтобы уложиться в
лимит службы перевода.

Перевод по умолчанию возвращается в поле ввода на место исходного текста; если
поле уже не активно или текст в нём успели изменить, перевод показывается в
окне. Внизу главного окна есть флажок «Копировать в буфер» — тот же
переключатель, что и в настройках скрипта. Когда он включён, перевод
копируется в буфер обмена после любого перевода: и когда вставляется в поле
ввода, и когда показывается в окне. В настройках скрипта два переключателя:
«Вставлять перевод обратно в поле ввода» и «Копировать перевод в буфер
обмена».

## Требования

SandFly версии не ниже 2. wam.tele2-summary проверен на API 3,
ymusic.video_rows, wam.nekogram-actions и wam.translator — на API 4.
